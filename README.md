# 📱 Mobile Price Prediction

A beginner-friendly Machine Learning application that predicts the price of a mobile phone based on its hardware specifications using **Linear Regression**.

The project includes a model-training script and a **Streamlit** web application for interactive predictions and model evaluation.

## 🎯 Project Objective

The objective of this project is to build a regression model that estimates a mobile phone's price from the following specifications:

- RAM
- Storage
- Battery
- Screen Size
- Camera
- Processor Score

The target variable is **Price**.

## 🧠 Machine Learning Approach

This project uses **Linear Regression** from `scikit-learn`.

The dataset is divided into:

- **80% training data**
- **20% testing data**

The split uses `random_state=42`, making the split reproducible.

The model is trained using the six input features and the `Price` column as the target.

## ⚙️ How the Model Is Trained

The `train_model.py` script performs the following steps:

1. Loads the mobile price dataset.
2. Selects the six input features.
3. Selects `Price` as the target.
4. Splits the data into training and testing sets.
5. Creates a `LinearRegression` model.
6. Trains the model.
7. Generates predictions for the test data.
8. Calculates MAE, MSE, and R² score.
9. Saves the trained model as `model/linear_regression_model.pkl`.

## 📈 Model Evaluation

The training script calculates three evaluation metrics:

### Mean Absolute Error (MAE)

MAE measures the average absolute difference between actual and predicted prices.

A lower MAE indicates smaller average prediction errors.

### Mean Squared Error (MSE)

MSE calculates the average squared difference between actual and predicted prices.

A lower MSE indicates smaller prediction errors, while larger errors have a greater effect because the errors are squared.

### R² Score

R² indicates how much of the variation in the target values is explained by the regression model.

The Streamlit application displays the **R² Score** and **Mean Absolute Error**.

## 🖥️ Streamlit Application

The `app.py` file creates an interactive web interface.

The application provides:

- 📊 Model performance metrics
- 📱 Mobile specification inputs
- 🔮 Mobile price prediction
- 📋 Entered specification summary
- 📈 Actual vs. predicted price visualization

When the user clicks **Predict Mobile Price**, the entered specifications are converted into a Pandas DataFrame and passed to the trained Linear Regression model.

The predicted price is then displayed in Indian Rupees (₹).

## 📈 Actual vs Predicted Prices

The application also compares the actual prices from the test set with the prices predicted by the trained model.

The project includes a chart where:

- Actual prices are taken from the test set.
- Predicted prices are generated by the Linear Regression model.
- Predictions closer to the actual values indicate smaller prediction errors.

## 🚀 Installation

### 1. Clone or download the project

Place the project on your computer with the structure shown above.

### 2. Create a virtual environment

Windows:

```bash
python -m venv venv
```

Activate it:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

The project dependencies are:

- pandas
- numpy
- scikit-learn
- streamlit
- joblib
- matplotlib

## 🏋️ Train the Model

Before running the application, make sure the dataset exists at:

```text
dataset/mobile_prices.csv
```

Then run:

```bash
python train_model.py
```

After successful training, the model is saved to:

```text
model/linear_regression_model.pkl
```

## ▶️ Run the Streamlit Application

Start the application with:

```bash
streamlit run app.py
```

Streamlit will provide a local URL in the terminal. Open that URL in a web browser.
